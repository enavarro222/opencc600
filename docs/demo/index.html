opencc600 — le vrai firmware, dans le navigateur

Ici tourne le firmware libre du compteur GEOID CC600, tel qu'il est flashé sur le compteur : l'ESP32-S3 est émulé dans la page par esp32sim (WebAssembly), son écran et sa puce nRF52 (touches, horloge, batterie, baromètre) sont simulés. Rien n'est envoyé nulle part.

La maquette de l'interface est le prototype cliquable ; le code est sur github.com/enavarro222/opencc600.

Chargement de l'émulateur…
  • 1 haut gauche · 2 bas gauche · 3 bas droite
  • Un clic : appui court. Maintenir ½ seconde : appui long (allumer, éteindre, arrêter une sortie).
  • (« Maintenir », « Menu », « Démarrer » : une aide du simulateur, le vrai compteur n'a pas d'écran tactile)
  • L'heure vient de ton ordinateur, la batterie est à 80 %. Le GPS se cale sur le trajet simulé ci-dessous.

Ton firmware d'origine

Le firmware GEOID n'est pas diffusé ici. Si tu as lu la flash de ton compteur (esptool read-flash 0 ALL dump.bin, 16 Mo), tu peux la faire tourner : le fichier reste dans ta page, rien n'est envoyé. Il contient tes sorties, tes réglages et tes appairages : ne le partage pas.
