opencc600 — prototype cliquable

Maquette de l'interface du firmware libre pour le compteur GEOID CC600. Clique sur les 3 boutons bleus (ou sur les libellés à l'écran). Le panneau de droite simule les événements de la sortie.

Écran réel : 240×320, 3 boutons. Code et docs : github.com/enavarro222/opencc600
