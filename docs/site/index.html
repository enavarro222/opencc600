Un firmware libre pour les compteurs vélo GEOID CC600 et CC700. Rouler en liberté.

Le firmware

  • Pages de sortie choisies selon la trace et les capteurs, grands chiffres, thème de nuit.
  • Altitude et D+ au baromètre, calés sur le GPS.
  • Traces depuis le téléphone : carte orientée, alerte hors trace, montées à venir.
  • Capteurs BLE : cardio, vitesse / cadence, puissance avec zones et calibration.
  • Sorties en FIT, qui survivent à une coupure de courant.

Il s'installe à côté du firmware d'origine, qui reste sur l'appareil : une commande le remet.

Essayer dans le navigateur Versions Code source (GPL-3.0)

Musette

L'application compagnon : envoie les traces et les réglages au compteur, récupère les sorties. Dans le navigateur, sur Android et iOS, sans compte : les sorties restent sur votre appareil.

Ouvrir Musette Code source (MIT)

Projet amateur non officiel, sans lien avec GEOID ni Magene. Installer un autre firmware peut annuler la garantie ou rendre l'appareil inutilisable : à vos risques.
